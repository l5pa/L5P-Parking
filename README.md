# Little 5 Points Parking Map

A mobile-first Progressive Web App for finding parking in Atlanta's Little Five Points neighborhood.

## Live Site
**[https://parking.l5pa.com/](https://parking.l5pa.com/)**

## Features

- **Interactive Map**: Leaflet.js with CartoDB Voyager tiles showing parking lot locations
- **Real-time Location**: Automatic geolocation with distance calculations in miles
- **Distance Sorting**: Parking sorted by proximity to your location
- **EV Charging Info**: See which lots have EV charging available
- **Validation Info**: Know which lots offer parking validation
- **Parking Capacity**: Number of spaces per lot where available
- **Rates & Details**: Pricing, addresses, and nearby landmarks
- **Mobile-First**: Optimized touch controls and responsive design
- **Offline PWA**: Installable on mobile devices with offline support
- **Live Updates**: Location tracking updates as you move

## Data Source

Parking data is managed in a [Google Sheet](https://docs.google.com/spreadsheets/d/1OuKDgbthkc03pr87yIu21M5RCLMaIuEsGDGbkqoq8cc) and fetched as CSV at runtime. No API key is required.

### Sheet Columns

| Column | Description | Example |
|---|---|---|
| `id` | Unique numeric ID | `1` |
| `name` | Lot name | `Findley Plaza Parking` |
| `description` | Additional details | `Public parking deck` |
| `address` | Street address | `1100 Euclid Ave NE` |
| `gps` | Coordinates (lat,lng) | `33.7650,-84.3485` |
| `evcharging` | EV charging available | `Yes` / `No` |
| `rates` | Pricing info | `$1.50/hr` or `Free` |
| `type` | Parking type | `Parking Lot`, `Parking Deck` |
| `landmark` | Nearby landmark | `Near Criminal Records` |
| `validation` | Validation available | `Yes` / `No` |
| `contact` | Contact info | Phone number or URL |
| `spaces` | Number of parking spaces | `45` |

To add or update parking locations, edit the Google Sheet directly — changes appear in the app on next load.

## Getting Started

### Local Development

This is a static site — no build step. To run locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/l5pa/L5P-Parking.git
   cd L5P-Parking
   ```

2. Start a local server (geolocation requires HTTPS or localhost):
   ```bash
   python3 -m http.server 8000
   # then open http://localhost:8000
   ```

3. Open `http://localhost:8000` in your browser.

### Map engines

The app supports two map engines:

- **Google Maps** (default) — requires an API key and Map ID (injected at deploy time).
- **Leaflet** — append `?engine=leaflet` to the URL. Uses CartoDB Voyager tiles, no API key needed. Kept as a rollback option.

To run the Google Maps engine locally:

1. Copy the example config: `cp config.example.js config.local.js`
2. Edit `config.local.js` and paste your `GOOGLE_MAPS_API_KEY` and `GOOGLE_MAPS_ID`
3. Open `http://localhost:8000`

`config.local.js` and the deploy-generated `config.js` are gitignored.

### Production config

In production, `config.js` is generated by `.github/workflows/deploy.yml` from the
`GOOGLE_MAPS_API_KEY` and `GOOGLE_MAPS_ID` repository secrets.

## Technical Details

- **Frontend**: Vanilla JavaScript, HTML5, CSS3
- **Map**: Leaflet.js with CartoDB Voyager tiles (free, no API key)
- **Data**: Google Sheets CSV endpoint
- **Geolocation**: HTML5 Geolocation API
- **PWA**: Service Worker with network-first data strategy
- **Distance**: Haversine formula, displayed in miles
